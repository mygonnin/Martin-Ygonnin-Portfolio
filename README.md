# Portfolio de Martin Ygonnin — V6

Site statique HTML5 / CSS3, sans framework ni backend, compatible avec GitHub Pages.

## Pages
- `index.html` : accueil, formation, expériences, projets majeurs et compétences.
- `projets.html` : études de cas du kit sanitaire (Bloc O) et du projet GE37 (Eiffage).
- `experiences.html` : OPmobility, BCD Ingénierie et engagement de réserviste.
- `contact.html` : coordonnées et liens professionnels.
- `style.css` : styles communs et mises en page responsive.

## Aperçu local
Ouvrir `index.html` dans un navigateur. Le bouton FR / EN fonctionne également en ouverture locale (`file://`) ; la mémorisation de la langue est facultative si le navigateur bloque le stockage local.

## Publication GitHub Pages
Déposer les quatre pages HTML, `style.css` et le dossier `assets/` à la racine du dépôt. Dans Settings > Pages, choisir la branche principale et le dossier `/`.

## Confidentialité
- Les deux rapports PDF du projet GE37 sont accessibles depuis la page Projets.
- Aucun rapport client confidentiel d'OPmobility, de BCD Ingénierie ou du Kit Sanitaire n'est publié.
- Vérifier les autorisations de diffusion des visuels et informations avant publication.
